## 📌 Project Overview

This is a **beginner-friendly** Data Science & Analytics project that
analyzes a simulated dataset of Uber-style rides. It covers every step
from the project checklist:

1. **Data Cleaning** — handling missing values and duplicate rows
2. **Visualization** — rides by hour, rides by area, fare distribution
3. **Analysis** — total revenue, average fare/distance/rating, busiest
   hour, most popular pickup area, distance-fare correlation
4. **Prediction Model** — a simple linear regression predicting fare
   from ride distance
5. **Dashboard Creation** — a single combined summary view

A **dummy dataset** is generated by the project itself (no external
downloads needed), simulating 500 realistic rides — including a few
intentionally missing values and duplicate rows so the cleaning step
has real issues to fix.

## ⚙️ How Each Step Works

### 1. Dataset (`generate_dataset.py`)
Simulates 500 Uber-style rides with pickup area, hour of day, distance,
fare, passenger count, and rating. Rides are more frequent during
morning/evening rush hours, and fares scale with distance — mimicking
real-world ride patterns. A few missing values and duplicate rows are
added on purpose.

### 2. Data Cleaning (`data_cleaning.py`)
- Removes duplicate rows
- Sorts data by date
- Fills missing `fare` values using the **average fare for that same
  pickup area** (more accurate than a single overall average, since
  fares vary a lot by location)
- Fills missing `rating` values using the overall average rating

### 3. Visualization (`visualize.py`)
- Bar chart of rides by hour of day (reveals rush-hour patterns)
- Bar chart of rides by pickup area (which areas are busiest)
- Histogram of fare distribution
- Bar chart of average fare by pickup area

### 4. Analysis (`analysis.py`)
Calculates:
- Total rides and total revenue
- Average fare, distance, and rating
- Busiest hour of day and most popular pickup area
- Correlation between distance and fare (do longer rides cost more?)

### 5. Prediction Model (`predict.py`)
Uses **Linear Regression** (a straight "line of best fit") to predict
a ride's fare based on its distance. Simple by design: distances and
fares are plotted as points, and `numpy.polyfit` finds the
best-fitting straight line — the same idea as `y = mx + b` from school
math.

### 6. Dashboard (`dashboard.py`)
Combines 4 key charts (rides by hour, rides by area, fare distribution,
fare prediction model) into one image for an at-a-glance summary.
